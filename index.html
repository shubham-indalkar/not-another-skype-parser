Not Another Skyper Parser

  1. Request an export of your Skype conversations.
  2. Download the exported file when available.
  3. Extract the TAR file:
    • On Windows: Use 7-zip or similar tool.
    • On Mac: Double-click the file to extract it.
  4. Important: Download the source code zip and extract it to the same folder as your Skype export.
  5. Select the messages.json file from your export.
